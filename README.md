# IELTSTEST

IELTS Preparation & Online Mock Testing Platform.

## Architecture
- **Frontend:** React 18, TypeScript, Vite, TailwindCSS v4, Ant Design, Radix UI (`ReactFrontEnd/`)
- **Backend:** Spring Boot 3.5.0, Java 17, MongoDB Atlas (`backend/ielts/`)
- **Cloud & AI:** OpenAI API, Azure Cognitive Speech Services, AWS S3, VNPay
